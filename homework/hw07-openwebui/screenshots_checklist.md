# Submission Screenshots Checklist

Take these screenshots and submit them with the project.

## 1. Project files
- Screenshot of the full project folder structure.

## 2. Kaggle dataset
- Screenshot of the Kaggle Netflix dataset page.
- Screenshot showing the CSV file downloaded or available.

## 3. Open WebUI Knowledge Base
- Screenshot of the Knowledge page.
- Screenshot of the new Knowledge Base named `Netflix Shows KB`.
- Screenshot showing `netflix_titles.csv` uploaded.
- Screenshot showing indexing completed.

## 4. Open WebUI tool/function
- Screenshot of the Tools or Functions page.
- Screenshot of the created function/tool.
- Screenshot showing the function code pasted from `openwebui_function_tool.py`.
- Screenshot showing the tool enabled.

## 5. System prompt
- Screenshot of the system prompt area.
- Screenshot showing the prompt from `system_prompt.txt` pasted into the model or chat settings.

## 6. Local server
- Screenshot of terminal running `python tools_server.py`.
- Screenshot of `http://localhost:5005/health` returning success.
- Optional: screenshot of `http://localhost:5005/country/France` in browser or Postman.

## 7. Tests
- Screenshot of `python -m pytest -v` output.
- Screenshot showing all tests passed.

## 8. Demo questions
- Screenshot of a KB-only question, for example: `List 5 Netflix titles from India`.
- Screenshot of a tool-only question, for example: `What currency is used in France?`
- Screenshot of a combined question, for example: `Show 3 Netflix titles from Japan and tell me Japan's currency.`

## 9. Final chat result
- Screenshot showing the assistant successfully answering using KB.
- Screenshot showing the assistant successfully answering using the tool.
